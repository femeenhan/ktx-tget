# [블로그 초안] 명절 KTX 취소표, 이제 폰이 대신 잡아줍니다 — ktx-tget

> ⚠️ 이 글은 초안입니다. `[ ]` 로 표시된 부분(다운로드 링크, 문의처, 스크린샷 등)을 채워 넣고 실제 발행 전에 문구를 다듬어 주세요.

---

## 명절 기차표, 새벽까지 새로고침만 누르다 잠들어 본 적 있으신가요?

추석·설날 KTX 예매는 오픈 몇 분 만에 마감되고, 그 뒤로는 **취소표와의 싸움**입니다. 문제는 취소표가 언제 풀릴지 아무도 모른다는 것 — 새벽 2시일 수도, 출발 1시간 전일 수도 있습니다. 결국 사람들은 코레일톡 새로고침 버튼을 몇 시간이고 누르다가 지쳐 잠들고, 눈뜨면 좌석은 이미 다른 사람이 채간 뒤죠.

그래서 만들었습니다. **ktx-tget** — 코레일톡 열차 목록 화면을 대신 지켜보고 있다가, 취소표가 뜨는 순간 자동으로 좌석을 클릭하고 예매까지 진행한 뒤 알림으로 깨워주는 안드로이드 도우미 앱입니다.

---

## ktx-tget이 하는 일

1. **코레일톡 열차 목록 화면을 2~3초 간격으로 자동 새로고침**
2. 원하는 열차의 좌석이 **매진 → 예매 가능**으로 바뀌는 순간 자동 감지
3. 좌석 가격 칸을 자동 탭 → 예매 바텀시트에서 **「예매」 버튼까지 자동 탭**
4. **승차권 정보 확인 화면**에 도달하면 강한 알림으로 사용자를 깨움
5. 그다음 **결제는 사용자가 직접** 진행 (결제 자동화는 하지 않습니다)

즉, "좌석 선점"까지만 자동화하고 실제 결제·개인정보 입력은 사용자가 눈으로 확인하며 직접 하는 구조입니다.

---

## 이런 분들께 추천합니다

- 명절마다 취소표 잡으려고 뜬눈으로 밤새는 분
- 출근/수업 중이라 실시간으로 새로고침을 누르고 있을 수 없는 분
- 특정 열차·좌석 등급만 노리고 있어서 조건에 안 맞는 표는 걸러내고 싶은 분

---

## 주요 기능

- **자동 새로고침 매크로**: 2.0초~3.0초 사이에서 간격 조절 가능
- **좌석 필터**: 자유석 제외 / 입석 제외 / 입석+좌석 조합 제외 등 원치 않는 좌석 유형은 자동으로 건너뜁니다
- **열차 번호 제외**: 특정 열차(정차역이 많거나 시간대가 안 맞는 열차 등)를 매크로 대상에서 뺄 수 있습니다
- **정차 안내 자동 확인**: 중간 정차 안내 팝업이 뜨는 열차를 자동으로 넘길지, 걸러낼지 선택 가능
- **예매 성공 알림 — 기본 / 강함 두 단계**
  - 기본: 알림 + 짧은 소리·진동
  - 강함: 알람 반복 + 강한 진동 + 전체 화면 알림 — **자는 사이에도 확실히 깨워줍니다**
  - 알림에 **「알림 중지」 버튼**이 있어서, 결제창(코레일톡)으로 넘어간 뒤에도 앱을 다시 열지 않고 바로 알람을 끌 수 있습니다

---

## 왜 앱스토어(Play 스토어)에는 없나요?

ktx-tget은 **접근성 서비스(Accessibility Service)**를 이용해 코레일톡 화면을 읽고 자동으로 탭하는 방식으로 동작합니다. 이런 자동화 방식의 앱은 Play 스토어 정책상 심사·배포가 까다로워, 현재는 **APK 파일을 직접 내려받아 설치하는 방식(사이드로드)**으로만 배포하고 있습니다.

- 스토어를 거치지 않기 때문에 **모든 구매자에게 동일한 APK 파일**을 드리고, 기기별 **라이선스 키**로 활성화하는 구조입니다.
- 최초 1회만 설치·인증하면 이후에는 평소처럼 사용하시면 됩니다.

> ※ 코레일톡 자동화 매크로 사용은 코레일 이용약관 및 관련 정책에 저촉될 수 있습니다. 본 앱은 좌석 선점만 보조하며, 실제 결제·이용에 대한 책임은 사용자 본인에게 있습니다. 참고용으로 사용해 주세요.

## 다운로드 및 설치 방법

1. 아래 링크에서 APK 파일을 내려받습니다. → **[다운로드 링크]**
2. 갤럭시 기준 설치 방법은 안내 문서를 참고해 주세요. → **[설치 가이드 링크 / docs/sideload_install_guide.md]**
   - Play 프로텍트 차단 해제
   - 「알 수 없는 앱 설치」 허용
   - 접근성 권한 켜기
3. 앱 실행 후 **내 기기 ID**를 복사해 **[문의처 / 카카오톡 오픈채팅 등]**로 보내주시면, 라이선스 키를 발급해 드립니다.
4. 받은 키를 앱에 입력하면 바로 사용 가능합니다.

```text
① APK 설치
   ↓
② 앱에서 기기 ID 복사 → 저에게 전송
   ↓
③ 라이선스 키 발급 → 전달받기
   ↓
④ 키 입력 → 활성화
   ↓
⑤ 접근성·알림 설정 후 사용 시작
```

## 사용 팁

- 코레일톡에서 **원하는 출발 시각이 목록 맨 위에 오도록** 미리 맞춰두세요. ktx-tget은 화면에 보이는 열차만 인식합니다.
- 밤새 켜둘 계획이라면 배터리 최적화 제외(**절대 절전 안 함**) 설정을 꼭 해주세요. 백그라운드 새로고침이 끊기지 않습니다.
- 「강함」 알림 모드를 추천합니다 — 취소표는 대부분 예고 없이, 새벽에 뜹니다.
