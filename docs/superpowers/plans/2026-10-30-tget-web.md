# tget.bigseasons.co.kr 판매·배포 웹 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 구매자가 혼자 다운로드·설치·활성화 요청까지 끝내고, 판매자가 웹 관리 화면에서 승인·APK 업로드를 하는 판매 창구를 세운다.

**Architecture:** 저장소 안 `web/`에 Next.js(App Router) 프로젝트를 두고 Vercel에 배포한다. 라이선스 상태 전이는 순수 함수(`web/lib/license.ts`)로 분리해 단위 테스트하고, 라우트 핸들러는 얇게 유지한다. 앱은 HMAC 키 검증을 버리고 서버 상태를 `HttpURLConnection`으로 조회해 72시간 오프라인 유예로 판단한다.

**Tech Stack:** Next.js 15 (App Router, TypeScript), Vitest, `@neondatabase/serverless`(Neon Postgres), `@vercel/blob`, Vercel Cron. 앱: Kotlin/Compose, `HttpURLConnection`, `org.json`(안드로이드 내장), JUnit4.

**Spec:** `docs/superpowers/specs/2026-10-30-tget-web-design.md`

## Global Constraints

- 서브도메인 `tget.bigseasons.co.kr`. 기존 `bigseasons.co.kr`(GitHub Pages)은 건드리지 않는다.
- 라이선스 종류: `lifetime` | `month` | `year`. 상태: `pending` | `active` | `expired` | `revoked` (앱 응답에는 `none` 추가).
- 1개월 = 달력 기준 +1개월, 1년 = +12개월. 연장은 현재 만료일에 더한다(만료 지났으면 승인 시각부터).
- 기기 식별은 `ANDROID_ID` 소문자만. 토큰 없음.
- 앱 오프라인 유예 72시간. 상태 확인 시점: 앱 열 때, 시작 누를 때, 실행 중 30분마다, `pending` 카드 표시 중 1분마다.
- 활성화 요청에는 입금자명(필수)과 환불 불가 동의(`agreed: true`, 필수)가 있어야 한다.
- 입금자명은 승인/회수 30일 뒤 null.
- 관리자는 1명, `ADMIN_PASSWORD` 환경변수 + 서명 쿠키(30일).
- 가격·계좌·오픈채팅·공지는 DB `settings`. 오픈채팅 초기값 `https://open.kakao.com/o/s1cF7MUi`.
- 푸터 표기: 빅시즌스 · 대표 한철민 · 사업자등록번호 674-66-00675 · 서울특별시 은평구 통일로 796 · 통신판매업 신고번호(없으면 「신고 준비 중」) · bigseasons.dev@gmail.com.
- release 서명은 정식 키스토어. 키스토어·비밀번호는 커밋 금지.
- 앱 기존 단위 테스트 58개는 계속 통과해야 한다(`DeviceLicenseTest`는 교체).
- 커밋 메시지는 이 저장소 관례대로 한국어 한 줄. 푸시는 하지 않는다.
- 랜딩·다운로드·가이드 화면 구현 전에 `ui-ux` 스킬을 호출한다(사용자 전역 지시).
