# ktx-tget 설치 안내 (구매자용)

> 판매자가 이 문서를 그대로 구매자에게 보내면 됩니다. 자세한 그림 안내는 웹에 있습니다.

## 주소

- 홈페이지: **https://tget.bigseasons.co.kr**
- 다운로드: **https://tget.bigseasons.co.kr/download**
- 사용 안내: **https://tget.bigseasons.co.kr/guide**

## 1. 설치 (처음 한 번, 5분)

1. **Play 프로텍트·Auto Blocker 끄기** — Play 스토어 → 프로필 → Play 프로텍트 → ⚙ → 「Play 프로텍트로 앱 검사」 끔. 갤럭시(One UI 6 이상)는 설정 → 보안 및 개인정보 보호 → Auto Blocker 끔. 설치 후 다시 켜도 됩니다.
2. **출처 허용** — 다운로드 페이지에서 APK를 받고 열면 「출처를 알 수 없는 앱」 창이 뜹니다. 브라우저(크롬·삼성 인터넷)에 **이 출처 허용**을 켭니다.
3. **설치** — 받은 `ktx-tget-<버전>.apk`를 열고 **설치**. 경고가 나오면 **자세히 → 그래도 설치**.

## 2. 활성화 요청

1. 앱을 열면 「활성화 요청」 카드가 보입니다.
2. **입금자명**을 적고 **기간**(1개월·1년·영구)을 고른 뒤, 카드에 보이는 **계좌로 입금**합니다.
3. 「승인 후 환불 불가」에 동의하고 **요청 보내기**를 누르면 「승인 대기 중」으로 바뀝니다.
4. 입금이 확인되면 판매자가 승인하고, 앱이 1분 안에 스스로 풀려 **「대기 중 / 시작」** 화면이 됩니다. 기기 ID를 따로 보낼 필요는 없습니다.

만료가 다가오면 홈에 「N일 남음」과 「연장 요청」이 보입니다. 같은 방법으로 연장합니다.

## 3. 사용 전 설정

- **접근성**: 설정 → 애플리케이션 → ktx-tget → ⋮ → **제한된 설정 허용** 후, 설정 → 접근성 → 설치된 앱 → ktx-tget **사용**.
- **알림** 허용, 배터리 **절대 절전 안 함** 권장.
- 코레일톡 열차 목록을 띄운 뒤 ktx-tget에서 **시작**. 결제는 직접 합니다.

자세한 설명은 https://tget.bigseasons.co.kr/guide 를 보세요.
