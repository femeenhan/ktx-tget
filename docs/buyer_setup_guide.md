# ktx-tget 설치 안내 (구매자용)

> 앱 0.2.0 화면 기준입니다. 판매자가 이 문서를 그대로 구매자에게 보내면 됩니다.

## 전체 순서

| 순서 | 할 일 | 시간 |
|------|--------|------|
| 1 | 판매자가 보낸 **APK** 설치 | 5~10분 |
| 2 | 앱에서 **기기 ID 복사** → 판매자에게 보내기 | 1분 |
| 3 | 판매자가 보낸 **라이선스 키** 입력 → 활성화 | 1분 |
| 4 | **접근성·알림·배터리** 설정 | 3분 |
| 5 | 코레일톡 열차 목록을 띄우고 **시작** | — |

---

# 1단계. APK 설치

## 1-1. 파일 받기

- **Google Drive 링크(권장):** 링크를 열고 `ktx-tget-release.apk`를 다운로드합니다. **내 파일 → 다운로드** 폴더에 저장됩니다.
- **카카오톡:** `ktx-tget-release-kakao.zip`을 저장하고, **내 파일**에서 압축을 풀면 `.apk`가 나옵니다. 카카오톡은 `.apk`를 직접 보낼 수 없어 zip으로 보냅니다.

## 1-2. Play 프로텍트 차단 풀기 (설치 전에 먼저)

「Google Play 프로텍트가 앱을 차단했습니다」가 나오면 경고를 무시하는 것만으로는 설치되지 않습니다.

**방법 A. Play 프로텍트 검사 끄기**

1. **Play 스토어** 실행
2. 오른쪽 위 **프로필** → **Play 프로텍트**
3. 오른쪽 위 **⚙** → **Play 프로텍트로 앱 검사** → **끔**

**방법 B. 갤럭시 Auto Blocker 끄기 (One UI 6 이상)**

1. **설정** → **보안 및 개인정보 보호** → **Auto Blocker**
2. **끔**

설치가 끝나면 다시 켜도 됩니다.

## 1-3. 출처를 알 수 없는 앱 허용 (처음 한 번)

1. **설정** → **애플리케이션** → 오른쪽 위 **⋮** → **특수 액세스** → **출처를 알 수 없는 앱 설치**
2. APK를 열 앱(**내 파일** 또는 **카카오톡**) 선택 → **이 출처 허용** 켜기

메뉴가 안 보이면 **설정** → **보안 및 개인정보 보호** → **더 많은 보안 설정** → **알 수 없는 앱 설치**에서 찾습니다.

## 1-4. 설치

1. **내 파일** → **다운로드** → `ktx-tget-release.apk` 탭
2. **설치**. 경고가 나오면 **자세히** → **그래도 설치**
3. 그래도 막히면 1-2를 다시 확인합니다.

> 접근성(화면 읽기)을 쓰는 앱이라 Play 스토어에 없습니다. 판매자에게 받은 파일이 맞다면 위 순서로 설치하면 됩니다.

# 2단계. 기기 ID 보내기

1. **ktx-tget** 앱을 엽니다.
2. 맨 위가 점선 테두리의 **「잠김」** 상태이고, 그 아래 **「라이선스 활성화」** 카드가 보입니다.
3. **내 기기 ID** 오른쪽 **「복사」**를 누릅니다.
4. 카카오톡 등으로 판매자에게 붙여 넣어 보냅니다.

> ⚠️ 휴대폰 설정에 있는 일련번호·IMEI가 **아닙니다.** 반드시 앱에 보이는 16자리 기기 ID를 보내 주세요.

---

# 3단계. 라이선스 키 넣기

판매자에게 `A3F2-9C1B-E047-1D8F` 같은 키를 받으면:

1. 같은 카드의 **라이선스 키** 칸에 붙여 넣습니다.
2. **「활성화」**를 누릅니다.
3. 「라이선스가 활성화되었습니다」가 뜨고, 맨 위가 **「대기 중」**과 검은 **「시작」** 버튼으로 바뀌면 성공입니다.

「라이선스 키가 올바르지 않습니다」가 뜨면 키를 다시 복사해 넣어 보고, 그래도 안 되면 판매자에게 기기 ID를 다시 보내 주세요.

# 4단계. 꼭 켜야 하는 설정

## 4-1. 접근성 (필수 — 안 켜면 아무 동작도 하지 않습니다)

직접 설치한 앱은 접근성이 「제한된 설정으로 제어됨」으로 잠겨 있을 수 있습니다. **①을 먼저** 하세요.

**① 제한된 설정 허용**

1. **설정** → **애플리케이션** → **ktx-tget**
2. 오른쪽 위 **⋮** → **제한된 설정 허용** → 잠금 화면(PIN·지문) 확인

**② 접근성 켜기**

- 앱 홈 아래쪽 **「접근성 권한」** 줄의 **「설정 열기」**를 누르거나,
- **설정** → **접근성** → **설치된 앱** → **ktx-tget** 으로 들어가
- **사용** 스위치를 켜고 **허용**을 누릅니다.

**③ 확인:** 접근성 화면에서 ktx-tget이 **사용 중**이고 「제한된 설정으로 제어됨」 문구가 없어야 합니다.

## 4-2. 알림 (필수)

- 앱에서 처음 **「시작」**을 누르면 알림 허용 창이 뜹니다. **허용**을 누릅니다.
- 밤에 자면서 쓸 거라면:
  - 앱의 **예매 알림**을 **「강함」**으로 둡니다. 끌 때까지 알람이 울립니다.
  - **설정** → **애플리케이션** → **특수 액세스** → **전체 화면 알림** → ktx-tget 허용
  - **설정** → **소리 및 진동**에서 **알람** 볼륨을 올립니다.

## 4-3. 배터리 (권장 — 밤새 쓸 때 끊기지 않게)

**설정** → **배터리** → **백그라운드 사용 제한** → ktx-tget을 **절대 절전 안 함**으로 둡니다.

# 5단계. 사용하기

## 5-1. 코레일톡 준비

1. 같은 휴대폰에 **코레일톡**을 설치하고 로그인합니다.
2. 출발역·도착역·날짜로 조회해 **열차 목록**을 엽니다.
3. 원하는 시간대 열차가 **목록 맨 위**에 오도록 출발 시각을 맞춥니다. 화면에 보이는 열차만 감지합니다.

## 5-2. ktx-tget 홈 화면 설정

| 항목 | 뜻 |
|------|-----|
| **새로고침 간격** | −/+로 2.0~3.0초 사이, 0.25초 단위로 조절 |
| **누를 좌석 칸** | 취소표가 난 칸 중 어디를 누를지. 일반실만 / 특실만 / 둘 다(일반실 먼저) |
| **예매 알림** | 결제 화면에 닿았을 때 알림. 끔 / 기본(알림과 짧은 진동) / 강함(끌 때까지 알람) |
| **좌석 유형 제외** | ON으로 둔 유형(자유석, 입석+좌석, 입석)만 남은 열차는 예매하지 않고 넘깁니다 |
| **제외할 열차번호** | 목록에 보이는 열차번호를 넣고 「추가」. 칩의 ×로 뺍니다. 넣는 즉시 적용 |
| **정차 안내 자동 확인** | ON이면 정차 안내 팝업에서 「확인」을 누르고 예매를 이어갑니다. OFF면 팝업에서 멈춥니다 |

## 5-3. 시작과 중지

1. 맨 위 **「시작」**을 누릅니다. 맨 위가 검게 바뀌며 **「실행 중」**이 됩니다.
2. **코레일톡 열차 목록 화면으로 돌아가** 그대로 둡니다. 앱이 새로고침을 반복하다가 취소표가 보이면 예매 시트를 열고 예매까지 진행합니다.
3. **결제 화면에 닿으면** 알림이 오고 매크로는 스스로 멈춥니다. **결제는 직접** 하세요.
4. 멈추려면 ktx-tget에서 **「중지」**를 누릅니다.

- 실행 중에도 설정을 바꿀 수 있고, 다음 새로고침부터 적용됩니다.
- 무슨 일이 있었는지는 홈 위 **「기록」**에서 볼 수 있습니다. 문제가 생기면 이 화면을 캡처해 판매자에게 보내 주세요.

# 자주 묻는 것

- **앱을 업데이트하면 키를 다시 넣어야 하나요?** 아니요. 새 APK를 덮어 설치하면 됩니다. 다만 업데이트 뒤 **접근성이 꺼질 수 있으니** 4-1을 다시 확인하세요.
- **휴대폰을 초기화하거나 바꿨어요.** 기기 ID가 바뀌므로 2단계부터 다시 진행해 새 키를 받아야 합니다.
- **시작했는데 아무 일도 안 일어나요.** 접근성이 켜져 있는지(4-1), 코레일톡 열차 목록이 화면 맨 앞에 있는지 확인하세요. 「기록」에 「코레일 앱이 앞에 있지 않습니다」가 보이면 코레일톡이 앞에 없는 것입니다.
- **코레일톡이 업데이트된 뒤로 안 돼요.** 코레일톡 화면이 바뀌면 ktx-tget도 고쳐야 할 수 있습니다. 판매자에게 코레일톡 버전(설정 → 애플리케이션 → 코레일톡)과 「기록」 캡처를 보내 주세요.
- **주의:** 코레일 이용약관은 자동화 프로그램 사용을 제한할 수 있으며, 계정 제재 위험은 사용자 본인이 판단해야 합니다.
